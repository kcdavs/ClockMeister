# ClockMeister — project log

## What this is
Website for ClockMeister, a 3D-printed mechanical pendulum clock (~$350; deadbeat escapement, four-wheel train, spring-driven, exposed mechanism). Customers configure filament colors per part zone in a 3D view and buy via Stripe Checkout.

Design: Bauhaus / Mondrian (strong grid, black rules, off-white ground, deliberate primary colors, geometric type, subtle mechanical motion). Not template-looking.

Constraints: no database, no accounts, no server to maintain.

## Stack
- Next.js (App Router) + TypeScript, plain CSS (CSS Modules), no Tailwind
- react-three-fiber for the 3D configurator (Stage 5)
- Vercel hosting (Stage 7)
- Stripe Checkout + one serverless function that sets price and validates colors (Stage 8)
- Filament colors in `data/filaments.json` (Stage 6)

## Structure
- `app/layout.tsx` — root layout wrapping every page; site title/description
- `app/page.tsx` — home page (`/`)
- `app/globals.css` — site-wide styles
- `public/` — static files served as-is (images, models)
- `package.json` — dependencies and npm scripts
- `.gitignore` — includes `.env*` so secrets are never committed

- `public/models/clock.glb` — web-ready clock model (~2 MB), generated by `npm run model`
- `models-src/` — original Onshape exports (gitignored; ~28 MB, never committed)
- `scripts/optimize-model.sh` — glTF-Transform pipeline: dedup → flatten → join (keep part names) → weld → prune → meshopt

## 3D model
Source: Onshape "Right Assembly" (the whole clock; a mirrored left version exists but isn't used). 93 parts, ~311k triangles, 9 Onshape colors.
Optimization took it from 27.7 MB / 11,261 draw pieces to 2.0 MB / 93 pieces, no detail lost.

Proposed color zones (to become a data file mapping part name → zone, Stage 5/6):
- Face / front frame: Part 3 (yellow; multi-color print with the numerals)
- Numerals: the 72 small black "Part N" segments — must contrast with the face
- Hands: Hour Hand, Minute Hand
- Wheels: 2nd/3rd/4th Wheel, Part 4 (maroon)
- Escapement: Mirror Esc Wheel, Mirror Esc Pallet (blue)
- Plates & motion works: Mirror Front/Back, Motion Works, Hour Wheel (white), Minute Arbor
- Pendant: Pendant, Spur gear (9 teeth) (light blue)
- Small gray parts: Hour Wheel (gray), Part 2 — may fold into another zone
- Fixed (not selectable): M3 screws, Pendulm Rod
Known issue: two parts are both named "Hour Wheel" (white and gray). Rename the gray one in Onshape on next export; until then distinguish by material color.
